# **Blazar Magic React Kit**

> This document holds the knowledge about the Blazar Magic React Kit. This template can be used to quickly create an application front end using react and redux. It also handles translates for English and Spanish.

 ### Featured in 
 [[Nova Grant]]

## Features

> - [[BlazarMagicReactKit Authorization]]
> 
> 	- The template supports auth through the use of JWT. It uses local session storage to store the token, username (called user but can be extended to be an object)
> 	- Rehydrated on refresh from local storage 
> - [[BlazarMagicReactKit Themes]]
> 	- The application uses [Matieral 👨‍💻](https://mui.com/material-ui/customization/theming/). I have created an easy way to adjust and add new themes. See here: [[BlazarMagicReactKit Themes]] to add new themes to the template. 
> 	- rehydrated on refresh from local storage 
> 
> -  [[BlazarMagicReactKit Preference Storage]]
> 	- Stores user desired view for now but easily extendable. 
> 	- Rehydrated on refresh from local storage 
> 
> -  [[BlazarMagicReactKit Translation]]
> 	- Stores user's desired language. Can be view at /language (for now)
> 	- Rehydrated on refresh from local storage 
>   - Uses i18n for translation
